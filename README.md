# Instacart-Market-Basket-Analysis-XGBoost
Predict whether a customer will reorder a product in their next order using XGBoost

### Project Overview

This project uses the Instacart Market Basket Analysis dataset to predict whether a customer will reorder a product in their next order. Customer purchase history and order-level features are used to train an XGBoost classifier.

### Dataset

The dataset contains anonymized customer orders and product purchase histories from Instacart. Due to its large size, the raw dataset is not included in this repository.

### Method
* Data preprocessing and feature engineering
* Creation of customer, product, and order-based features
* Training an XGBoost classification model
* Evaluation using classification metrics such as Precision, Recall, F1-score, and ROC-AUC
